# Instrucciones para Trabajo en mastexo.com

## 🎯 Tu Misión: Buscar Clientes para mastexo.com

Tienes 7 skills especializados en tu repertorio para ayudar con prospección, venta y conversión. Tu rol es activarlos automáticamente basado en lo que el usuario solicita.

---

## 📚 Skills Disponibles

### 1. **investigacion-mercado** `skills/investigacion-mercado/SKILL.md`
**Para**: Validar mercados, identificar oportunidades, entender demanda
**Palabras clave**: "validar mercado", "¿existe demanda?", "tamaño de mercado", "tendencias", "competencia"

### 2. **persona-cliente** `skills/persona-cliente/SKILL.md`
**Para**: Definir cliente ideal, segmentación, personalización
**Palabras clave**: "cliente ideal", "persona", "quién es mi cliente", "target market", "segmentación"

### 3. **lead-magnet** `skills/lead-magnet/SKILL.md`
**Para**: Crear imanes de leads, construir listas de email, atraer prospectos
**Palabras clave**: "lead magnet", "imán de leads", "construir lista", "descarga gratuita", "guía gratis"

### 4. **cartas-ventas** `skills/cartas-ventas/SKILL.md`
**Para**: Emails de prospección, outreach, secuencias de ventas
**Palabras clave**: "email de prospección", "outreach", "secuencia de emails", "cold email", "prospección"

### 5. **guion-ventas** `skills/guion-ventas/SKILL.md`
**Para**: Preparación de llamadas, cierre de ventas, manejo de objeciones
**Palabras clave**: "guión de ventas", "llamada de cierre", "sales call", "conversación de venta", "objeciones"

### 6. **presentacion-ventas** `skills/presentacion-ventas/SKILL.md`
**Para**: Decks de presentación, pitch meetings, ROI presentations
**Palabras clave**: "presentación", "deck de ventas", "pitch deck", "presentation", "propuesta"

### 7. **pagina-ventas** `skills/pagina-ventas/SKILL.md`
**Para**: Páginas de conversión, sales pages, landing pages largo formato
**Palabras clave**: "página de ventas", "sales page", "conversión", "landing page", "copy de venta"

## 🔄 Flujo Completo de Prospección

Cuando un usuario quiera buscar clientes, procede en este orden:

```
FASE 1: INVESTIGACIÓN
└─ investigacion-mercado
   • Valida si hay mercado real
   • Estima TAM/SAM/SOM
   • Identifica oportunidades

FASE 2: DEFINICIÓN  
└─ persona-cliente
   • Define exactamente a quién buscar
   • Entiende sus pain points
   • Identifica canales

FASE 3: CAPTURA
└─ lead-magnet
   • Crea el gancho
   • Construye lista de email
   • Califica prospectos

FASE 4: PROSPECCIÓN
└─ cartas-ventas
   • Secuencia de outreach
   • Follow-ups
   • Nutrición de leads

FASE 5: CONVERSACIÓN
└─ guion-ventas
   • Prepárate para meetings
   • Manejad objeciones
   • Cierra sales

FASE 6: PRESENTATION (Si aplica)
└─ presentacion-ventas
   • Deck profesional
   • ROI calculations
   • Propuesta formal

FASE 7: CONVERSIÓN
└─ pagina-ventas
   • Página de cierre
   • Confirmación de venta
   • Onboarding
```

## 🚀 Cómo Activar Cada Skill

### Cuando el usuario diga cosas como:

**"Necesito validar si hay mercado para..."**
→ Lee `skills/investigacion-mercado/SKILL.md` y colabora mediante:
- Investigación de tamaño de mercado
- Validación primaria (entrevistas)
- Análisis de competencia
- Documento de conclusiones

**"¿Quién es mi cliente ideal?"** o **"Define mi persona de cliente"**
→ Lee `skills/persona-cliente/SKILL.md` y colabora mediante:
- Entrevista de descubrimiento
- Construcción de persona detallada
- Identificación de canales
- Validación contra clientes reales

**"Ayúdame a crear un lead magnet"** o **"Necesito construir lista"**
→ Lee `skills/lead-magnet/SKILL.md` y colabora mediante:
- Identifica el micro-problema
- Recomienda formato
- Crea contenido
- Escribe copy de captura

**"Necesito un email de prospección"** o **"Cómo hago outreach?"**
→ Lee `skills/cartas-ventas/SKILL.md` y colabora mediante:
- Estructura la secuencia
- Escribe sujetos lines
- Body copy persuasivo
- CTAs claros

**"Cómo preparo una llamada de venta?"** o **"Manejo de objeciones"**
→ Lee `skills/guion-ventas/SKILL.md` y colabora mediante:
- Estructura la conversación
- Antícipa objeciones
- Proporciona frases
- Técnicas de cierre

**"Necesito una presentación"** o **"Prep meeting con cliente"**
→ Lee `skills/presentacion-ventas/SKILL.md` y colabora mediante:
- Estructura de diapositivas
- Discovery integration
- Cálculos de ROI
- Case studies

**"Escribe una página de ventas"** o **"Conversión de visitantes"**
→ Lee `skills/pagina-ventas/SKILL.md` y colabora mediante:
- Marco PAS
- Apilamiento de beneficios
- Social proof
- Urgencia/scarcity

## 📝 Instrucciones Operacionales

Cuando trabajes en proyectos de mastexo.com:

1. **Identifica la necesidad** del usuario basado en sus palabras
2. **Lee el SKILL.md relevante** de la carpeta skills/
3. **Sigue el workflow** específico del skill
4. **Proporciona entregables concretos** (no solo teoría)
5. **Itera basado en feedback** del usuario
